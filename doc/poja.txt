*poja-nvim.txt*  Poja code generation for Neovim

==============================================================================
INTRODUCTION                                    *poja-intro*

poja.nvim is a Neovim plugin for generating and editing Java code in
Poja-generated projects (https://poja.io). It provides project detection,
layered file scaffolding, and a visual field editor.

==============================================================================
COMMANDS                                        *poja-commands*

:PojaApplication                               *:PojaApplication*
  Show the path to the PojaApplication.java class in the current project.
  Reports "Not a Poja project" if none is found.

:PojaCreate                                     *:PojaCreate*
  Interactively create a Poja-pattern Java file. Prompts for:
    1. File type (Entity, Controller, Service, Repository, Mapper, Event,
       Event Handler, DAO, Validator, Exception, DTO)
    2. Class name
  Files are written to the correct subdirectory under src/main/java/ using
  templates matching HEI Admin API conventions.

:PojaCreateAttribute                            *:PojaCreateAttribute*
  Open a floating window with checkbox controls to edit entity field
  annotations. Navigate fields with j/k, move between annotation presets
  with h/l, toggle with Space or Enter, edit preset parameters with v,
  save with :w, and close with q. Available presets:

    NotNull  NotBlank  NotEmpty  Size(min,max)
    Min      Max       Email     Pattern(regexp)

==============================================================================
CONFIGURATION                                   *poja-config*

The plugin can be configured by calling setup() with an options table:

    require("poja").setup({
      detect = { enabled = true },
    })

All options default to true. No configuration is required for basic usage.

==============================================================================
HEALTH                                         *poja-health*

Run :checkhealth poja to verify:
  - Poja project detection
  - Template loading
  - Field parser module
  - Command registration
